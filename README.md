# VFD-S1-2R2 · 单相 220V 进 / 三相 220V 出 / 2.2kW 变频器

一款以 **GD32F103C8T6** 为主控的小型通用变频器完整设计方案：功率级参数计算、器件选型 BOM、控制算法（SVPWM + V/F）、保护策略、寄存器级固件、接线与端子图纸。

> 本仓库为工程设计与参考实现，**未经实机验证**。上电前务必按 `docs/` 第 10 章的检查清单逐项确认，尤其是自举充电、FO 极性与保护定值标定。

## 规格

| 项目 | 参数 |
|---|---|
| 输入 | 单相 220VAC ±15%，50/60Hz，输入电流约 16.8A |
| 输出 | 三相 0~220VAC，0~400Hz，2.2kW（10A RMS） |
| 控制 | V/F 开环 + 转矩提升 + AVR，SVPWM，8kHz（2~16kHz 可调） |
| 过载 | 150%/60s，180%/10s，200% 立即跳闸 |
| 保护 | 过流、过压、欠压、过温、过载（I²t）、IPM 故障 |
| 通讯 | Modbus-RTU（RS485），03/06/16 功能码 |

## 快速开始

看图：先看 `docs/figures/01_主电路接线图.png` 与 `03_端子定义图.png`，它们就是接线依据。

编译固件：

```bash
cd firmware
make            # 需要 arm-none-eabi-gcc 工具链
make size       # 查看 Flash/RAM 占用
```

重新生成图纸（改尺寸或改标注后）：

```bash
cd hardware/tools
pip install matplotlib
python make_figures.py
```

## 设计要点（三句话）

1. **220V 电机 + 311V 母线 = SVPWM 线性区上限**，m≈1.155，靠 AVR 抵消电网波动，母线跌落就只能过调制。
2. **电池容量的账要按纹波电流算，不是只看容量**：单相整流电容纹波电流 ≈1.7 倍负载直流，2×1500µF 是下限。
3. **过流保护必须有硬件比较器进 BKIN**，软件 ADC 只做监视和 I²t——这是能不能扛住输出短路的分水岭。

## 限制

- 非隔离控制地：RS485/AI 与外部设备共地时需加隔离器
- 无 PFC：2.2kW 时 PF≈0.62，谐波要求严的场合请降额至 1.5kW
- 单电阻采样：不能做闭环矢量，低速重载能力有限
