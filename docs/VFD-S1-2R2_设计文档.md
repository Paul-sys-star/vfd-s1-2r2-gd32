## 1. 产品定义

### 1.1 目标应用

小型风机、水泵、传送带、包装机、木工机械、空压机辅机等"单相电源、三相电机"的场合。这类现场的共同约束是：只有单相 220V 市电、安装空间小、成本敏感、维护人员不具备示波器。

设计上因此做了三个取舍：

1. **不做 PFC**。单相 2.2kW 无 PFC 时输入功率因数约 0.62、输入电流约 16.8A，前端必须配 25A 断路器。若客户现场对谐波有要求（如 GB 17625.1），改用 1.5kW 档位或增加无源 PFC 电感。
2. **不做电流闭环矢量控制**。单电阻母线采样无法直接获得三相电流相位，做闭环矢量需要三电阻或霍尔传感器，成本与调试复杂度都会上一个台阶。V/F + 转矩提升已能满足风机水泵与一般恒转矩负载。
3. **控制地直接以母线负极（N-）为参考，非隔离**。省掉隔离电源与光耦，成本最低；代价是 RS485 与模拟量通道必须自行加隔离器件才能与外部设备共地。

## 2. 系统架构

整机分三块：功率板（EMI + 整流 + 母线 + IPM + 采样）、控制板（MCU + 驱动接口 + 人机 + 通讯）、结构与散热。

![主电路接线图](figures/01_主电路接线图.png)

功率通路走向：`L/N → 保险丝+压敏 → EMI 滤波 → 充电限流电阻（并联 K1）→ 整流桥 → 母线电容 → IPM → U/V/W → 电机`。

信号通路走向：`母线分压/分流电阻/NTC/IPM FO → MCU ADC 与 BKIN → SVPWM → 6 路 PWM + 死区 → IPM`。

## 3. 主电路设计与参数计算

### 3.1 输入侧

**输入电流**

\[
I_{in}=\frac{P_{out}}{\eta \cdot PF \cdot U_{in}}=\frac{2200}{0.96 \times 0.62 \times 220}\approx 16.8\text{A}
\]

- 保险丝：25A 慢断（aR 或 gG 均可，按短路能力选型）
- 整流桥：GBJ2510（25A / 1000V），或两只并联 KBJ1506 分担损耗
- 输入端子与内部走线：≥4mm²，端子载流按 25A 设计
- 压敏电阻：MOV 470V/14mm，吸收雷击与操作过电压

**EMI 滤波**

| 器件 | 参数 | 作用 |
|---|---|---|
| 共模电感 | 2.2mH，20A 铁氧体/非晶 | 抑制共模噪声（PWM 共模电流主要路径） |
| X 电容 | 0.22µF / 275VAC ×2 | 抑制差模噪声 |
| Y 电容 | 4700pF / 400VAC ×2 | 抑制共模，漏电流 <0.75mA（Class A 允许 3.5mA） |
| 放电电阻 | 与 X 电容并联，1MΩ | 断电 1s 内 X 电容放电到安全电压 |

> Y 电容容量直接决定漏电流，取值不能随意加大；漏电流超标会导致前端漏电保护器误跳。

### 3.2 母线

**母线电压**

\[
V_{dc} = \sqrt{2}\,U_{in} \approx 1.414 \times 220 = 311\text{V}
\]

- 母线电容耐压：450V（311V 额定 + 15% 电网偏高 + 制动泵升，留 30% 以上裕量）
- 过压保护定值 400V，欠压定值 200V

**电容容量**

按半个工频周期内电容放电、允许纹波 ΔV 估算：

\[
C = \frac{I_{dc}\,\Delta t}{\Delta V} = \frac{7.4 \times 0.004}{0.010} \approx 2960\mu F
\]

取 **2×1500µF / 450V（合计 3000µF）**，ΔV ≈ 10V（Δt=4ms）~ 20V（Δt=8ms 极端），母线谷值约 290V，仍能保证 220V 输出不进入过调制。

**纹波电流校验（关键，容易漏）**

单相整流的电容纹波电流约为负载直流的 1.6~1.8 倍：

\[
I_{c,rms} \approx 1.7 \times 7.4 \approx 12.6\text{A}
\]

两只并联各承担约 6.3A。选 105℃ / 5000h 低 ESR 品，单只 100Hz 纹波额定 ≥8A，且实际使用不超过额定的 80%。若实测电容顶温升 >10℃，加到 3 只或改用 2200µF 品。

**泄放电阻**

100kΩ / 2W 直接并在母线上，断电后母线电压按 τ = RC = 100k×3000µF = 300s 衰减。**这不是安规意义上的快速放电**，因此产品上必须贴"断电 5 分钟后再开盖"警示，并加母线带电指示灯（串联 3 只 100kΩ + 氖灯/ LED）。

### 3.3 IPM 选型

**输出相电流**

\[
I_{out}=\frac{P_{out}}{\sqrt{3}\,U_{line}\,\eta_{inv}\cos\varphi}=\frac{2200}{1.732 \times 220 \times 0.97 \times 0.85}\approx 7.0\text{A (RMS)}
\]

峰值 9.9A；150% 过载时 10.5A RMS / 14.8A 峰值。

| 方案 | 型号 | 额定 | 适用 | 说明 |
|---|---|---|---|---|
| 主选 | 三菱 PSS15S92F6-AG | 600V / 15A（Icp 30A） | ≤1.5kW 或 40℃ 以下 2.2kW | DIPIPM，内置 HVIC、自举二极管、SC 保护 |
| 推荐 | 富士 6MBP20RH060-50 | 600V / 20A | 2.2kW 连续、50℃ 环境 | 裕量更足，成本略高 |
| 备选 | 士兰微 SD20M60ACL | 600V / 20A | 同上，国产替代 | 需核对自举与 FO 时序 |

驱动侧要点：

- 自举电容 10µF/50V 陶瓷 + 0.1µF 高频并联，自举二极管用 IPM 内置或外加 UF 快恢复
- 每相栅极串 10~22Ω 电阻抑制 di/dt 与振荡
- FO 输出为开漏低有效，直接接 MCU BKIN（PB12），并加 10kΩ 上拉到 3.3V
- IPM 的 N 端（母线负极）与控制 GND 共点，采样点取在 N 端铜箔靠 IPM 一侧，避免开关尖峰进入采样

### 3.4 充电限流与制动

**充电限流**

母线 3000µF 从 0 充到 311V，储能：

\[
E=\tfrac{1}{2}CU^{2}=0.5 \times 3000\mu F \times 311^{2} \approx 145\text{J}
\]

用 20Ω / 20W 绕线（脉冲耐受型）限流，初始峰值电流 15.5A，充电时间常数 τ = 60ms，约 250ms 达到 250V。K1 继电器在母线 >250V 且延时 250ms 后吸合旁路。

> 若省掉 K1，20Ω 电阻长期通电会烧毁——这是低成本机型最常见的失效点，必须有旁路。

**制动（选配）**

- 制动电阻：100% 制动转矩时 \(R = V_{dc}^2/P = 311^2/2200 \approx 44\Omega\)，取 50Ω/300W；轻载制动可用 100Ω/200W
- 制动单元：外置 IGBT + 续流二极管，或用带制动斩波的 IPM 型号
- 制动阈值：母线 380V 开通，360V 关断，占空比按母线电压滞环控制
- 若不装制动单元，PB 端子必须悬空并加绝缘盖，禁止短接 P(+)-PB

### 3.5 散热

损耗估算（额定点）：

| 部位 | 损耗 | 说明 |
|---|---|---|
| IPM 导通 | ≈25W | 15A 器件 7A RMS，VCE(sat) 约 1.7V，3 桥臂 |
| IPM 开关 | ≈18W | 8kHz，Eon+Eoff ≈ 2.2mJ/脉冲（按数据手册曲线插值） |
| 整流桥 | ≈9W | 16.8A 输入，两只二极管串联导通 |
| 其他（电容/继电器/辅源/采样） | ≈8W | |
| **合计** | **≈60W** | 效率 96.4% |

散热器热阻要求（环境 40℃、结温 125℃、壳温 100℃）：

\[
R_{th,sa} \le \frac{T_c - T_a}{P_{loss}} = \frac{100-40}{60} \approx 1.0\text{K/W}
\]

工程取值 **Rth ≤ 0.6K/W**（留 40% 余量）：120×80×60 铝型材 + 80×80×25（12CFM）风扇强制风冷可满足。风扇由 MCU 控制，建议"上电常转"，仅在待机 10 分钟后降速，避免频繁启停。

## 4. 控制策略

### 4.1 SVPWM

调制采用"正弦参考 + 零序（共模）注入"，与七段式扇区法等价：

\[
d_a = 0.5 + 0.5\,m\cos\theta - \frac{\max(s)+\min(s)}{2},\quad s_{a,b,c}=\tfrac{1}{2}m\cos(\theta \mp 120^\circ)
\]

- 线性区 \(m \le 2/\sqrt3 = 1.1547\)，比 SPWM 多 15.5% 电压利用率
- 220V 电机 + 311V 母线时 \(m = 1.633 \times 220 / 311 = 1.155\)，正好处在线性区上限——这是本方案的本质约束，母线跌到 290V 时就需要过调制或降频
- 过调制区按六边形边界钳位，最高可到 6-step

载波与中断时序：

| 项目 | 取值 |
|---|---|
| 定时器 | TIMER0，中心对齐，PSC=0，CAR=4500 |
| 载波频率 | 72MHz / (2×4500) = 8kHz |
| 死区 | DTG=0x88 → (64+8)×2×13.89ns ≈ 2.0µs |
| 更新中断 | 每个载波周期一次（125µs），在计数谷点写 CC 寄存器 |
| 最小脉宽 | 1.2µs，低于此值窄脉冲会被 IPM 吞掉造成电流畸变 |

### 4.2 V/F 曲线

![V/F 曲线与降额](figures/04_VF曲线与降额.png)

\[
U(f)=\begin{cases}
\dfrac{U_N}{f_N}f + U_{boost}\left(1-\dfrac{f}{f_N}\right), & f<f_N\\[6pt]
U_N, & f \ge f_N
\end{cases}
\]

- 线性 V/F：默认，适合恒转矩负载（传送带、挤出机）
- 平方转矩：\(U \propto f^2\)，适合风机水泵，低频电流小、噪声低
- 转矩提升：默认 6%（0Hz 提升 12V），0.5Hz 起动转矩可达 150% 以上
- 基频可设 10~400Hz；基频以上恒压弱磁，转矩按 1/f 下降

**AVR**：用实测母线电压反算调制指数 \(m = 1.633\,U_{target}/V_{dc}\)，电网 ±10% 波动时输出电压波动可控制在 ±1% 内；母线过低时 m 自动顶到 1.15 上限，此时输出电压随母线下跌（属物理极限，不可修复）。

### 4.3 死区补偿与最小脉宽

死区 2µs 在 8kHz 下载波周期占 1.6%，低速时（输出 5V）造成的电压误差可达 30%。补偿方式：

\[
d_k \leftarrow d_k + \operatorname{sign}(i_k)\cdot\frac{t_{dead}}{T_{pwm}}
\]

本方案只有母线单电阻，无法直接测三相电流相位，故用母线电流幅值 + 固定功率角（约 26°）重构三相电流符号，属于近似补偿：低速轻载时补偿效果有限，重载时基本准确。

### 4.4 载波频率与降额

| 条件 | 动作 |
|---|---|
| 散热器 85℃ | 载波 8kHz → 4kHz，输出电流上限降至 90% |
| 散热器 95℃ | 跳闸 Err06 |
| 输出电流 > 8A | 载波降至 4kHz（降低开关损耗） |
| 环境 50℃ | 连续输出电流按曲线降至 88% |

降额曲线见图 4(b)(c)。载波降低会带来低速脉动与噪声增大，因此冷却后自动恢复 8kHz。

## 5. 采样与保护

### 5.1 采样通道

| 通道 | 信号 | 换算 | 精度 |
|---|---|---|---|
| ADC0_CH0 | 母线电压 | 750kΩ/5.1kΩ 分压，1 LSB = 0.119V | ±2V |
| ADC0_CH1 | 母线电流 | 2mΩ 分流 + ×25 放大，50mV/A，中点 1.65V | 16mA/LSB |
| ADC0_CH2 | 散热器 NTC | 10kΩ B=3950 上拉，B 公式换算 | ±1℃ |
| ADC0_CH3 | 面板电位器 | 0~100% 映射到 0~上限频率 | — |
| ADC0_CH4/5 | AI1 / AI2 | 0~10V、4~20mA | ±1% |

> 逐波限流的真正执行者是**硬件比较器**（LM393，阈值 22A 对应 1.10V），其输出直接拉低 BKIN；MCU 的 ADC 只做监视、I²t 积分与显示。仅靠软件 ADC 做不到 125µs 级的可靠过流保护。

### 5.2 保护定值与动作

| 保护 | 定值 | 延时 | 动作 | 故障码 |
|---|---|---|---|---|
| 硬件过流 | 25A 峰值 | <10µs | BKIN 封管 + 故障锁定 | Err01 |
| 逐波限流 | 22A 峰值 | 逐周期 | 收缩占空比，不跳闸 | — |
| 过压 | 400V | 4ms 消抖 + 415V 立即 | 封管 | Err03 |
| 欠压 | 200V | 30ms | 封管（预充电期间屏蔽） | Err04 |
| 过载 | 150%/60s、180%/10s | I²t 积分 | 封管 | Err05 |
| 过温 | 95℃ | 500ms | 封管 | Err06 |
| IPM 故障 | FO 低 | 1 载波周期 | 封管 | Err07 |
| 输出短路 | 上电自检 / 运行中 FO | 立即 | 封管 | Err01/07 |
| 参数校验 | CRC 失败 | 上电 | 回滚默认值 | Err09 |

**I²t 模型**：以额定电流为 1pu，热量累积速率 \(k = (I_{pu}^2-1)\)，150% 时 k=1.25，累积到 7500（pu²·s）跳闸，对应 60s；180% 时 k=2.24，对应 33s… 实际按 10s 跳闸标定，故取阈值时按最严工况（180%/10s）反推，得到 7500 更接近 150%/60s 曲线，二者之间用查表式修正。

**故障处理**：故障后 PWM 立即封锁，K1 断开，故障继电器动作（TA-TC 闭合），数码管显示 `Err xx`，必须按 STOP 或外部复位（S3）才允许重新起动；故障码与运行小时数存入 Flash，便于售后分析。

## 7. 结构与 EMC

1. **走线与间距**：母线强电与控制线间距 ≥8mm（爬电）；功率地与信号地单点连接于 IPM 的 N 端。
2. **铜箔载流**：2.2kW 输入 16.8A，按 1oz 铜箔 1mm/A 的保守规则需 ≥17mm 宽；实际用 2oz 铜 + 补锡，母线正负极各 ≥12mm。
3. **开关节点**：IPM 输出到 U/V/W 端子的走线尽量短（<30mm），并远离采样运放输入。
4. **地平面**：控制板完整地平面，ADC 输入串 100Ω + 1nF RC 滤波，NTC 与电位器加 100nF。
5. **安规**：L-N 之间加 X 电容与压敏；PE 与机壳直接连接；变压器/电感骨架满足加强绝缘。
6. **防护**：整机 IP20，接线端子加防护盖；风扇进风口加防尘网。

调度优先级（高→低）：`BKIN 硬件封锁` > `ADC EOC` > `TIMER0 更新（调制）` > `1ms 慢任务` > `485 解析`。

时间预算：调制中断约 40µs（含浮点三角函数，C8T6 无 FPU，用查表 + 线性插值可降到 15µs，推荐后续优化）。

## 11. 设计限制与后续升级

1. **非隔离控制地**：RS485、AI 通道若需与外部设备共地，必须加数字隔离器（如 ADuM1201）与隔离运放，否则共模电压会打穿接口。
2. **无 PFC**：2.2kW 输入电流 16.8A、PF 0.62，不符合严格谐波标准；需要时降额到 1.5kW 或加无源 PFC。
3. **无闭环矢量**：低速（<3Hz）带载能力受限，转矩提升过大（>10%）会引起过流，长时间低速运行需加强散热。
4. **单电阻采样**：无法做三相电流闭环，也无法精确死区补偿；升级方向是三电阻采样 + FOC（MTPA/弱磁），此时需把控制周期提到 10kHz 以上并换用带 FPU 的 MCU（如 GD32F303 / GD32E103）。
5. **软件未经实机验证**：本仓库固件为寄存器级参考实现，外设时序与保护定值必须按第 10 章逐项实测标定后才能上机，尤其是自举充电时间、FO 极性与 I²t 系数。
6. **EMC 认证**：传导骚扰需按 GB/T 22677、辐射按 GB 4824 实测；共模电感与 Y 电容参数是最主要的调节手段。
